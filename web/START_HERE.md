## Quick Start (5 Minutes)

### Terminal 1: Start Convex

```bash
cd web

# Initialize Convex (will open browser to login/signup)
bunx convex dev
```

**What happens:**
1. Opens browser → Create free Convex account
2. Creates new project
3. Deploys your schema & functions
4. Generates `.env.local` with connection URL
5. Starts watching for changes

**Keep this terminal running!**

---

### Terminal 2: Start Web App

```bash
cd web

# Start Vite dev server
bun dev
```

**What happens:**
1. Compiles React app
2. Starts on http://localhost:5173
3. Hot reload enabled

## Next: Build the UI (Follow NEXT_STEPS.md)

Now that Convex is running, build the frontend:

### Step 1: Setup Convex Provider (10 min)

Edit `src/main.tsx`:

```typescript
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { ConvexProvider, ConvexReactClient } from 'convex/react'
import './index.css'
import App from './App.tsx'

const convex = new ConvexReactClient(import.meta.env.VITE_CONVEX_URL!)

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <ConvexProvider client={convex}>
      <App />
    </ConvexProvider>
  </StrictMode>,
)
```

### Step 2: Test Connection (5 min)

Replace `src/App.tsx`:

```typescript
import { useQuery } from 'convex/react'
import { api } from '../convex/_generated/api'

function App() {
  const stats = useQuery(api.analyses.stats)

  if (stats === undefined) {
    return <div className="p-8">Loading...</div>
  }

  return (
    <div className="min-h-screen bg-gray-50 p-8">
      <h1 className="text-3xl font-bold mb-4">🌿 EIA Analyzer</h1>
      <div className="bg-white p-6 rounded-lg shadow">
        <h2 className="text-xl font-semibold mb-4">Stats</h2>
        <pre>{JSON.stringify(stats, null, 2)}</pre>
      </div>
    </div>
  )
}

export default App
```

Refresh browser → Should see stats!

## Troubleshooting

### "Convex not found"
```bash
bun add -g convex
```

### "VITE_CONVEX_URL not defined"
- Make sure `convex dev` finished successfully
- Check `.env.local` exists
- Restart Vite (`bun dev`)

### "Can't connect to Convex"
- Ensure `convex dev` is running
- Check Convex Dashboard for errors
- Verify `.env.local` has correct URL
